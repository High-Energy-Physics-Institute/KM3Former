# Results

## exp_001_baseline_local_smoke

Commit `4cec1d0`; used `data/muon_data_7224_7247.h5` with 21,555 events split into 17,244 train / 2,155 val / 2,156 test, and kept the baseline smoke setup in `runs/muon_count_smoke` (`model_dim=128`, `num_heads=4`, `num_encoder_layers=4`, `dim_feedforward=256`, `pairwise_neighbors=16`, `batch_size=32`, `epochs=1`, CPU). Best validation loss was `0.986383` and test accuracy was `0.502319`; confusion matrix (true rows, predicted cols) was `[[439, 140, 126], [309, 157, 233], [138, 127, 487]]`, so this is a usable baseline to keep. Initial note: the model already learned nontrivial structure after one epoch, but class `1` was the main weakness and was frequently confused with classes `0` and `2`.

## exp_008_capacity_push

Commit `52f65ff`; used the saved run in `runs/exp_008_capacity_push` with the resolved config from that directory (`model_dim=192`, `num_heads=8`, `num_encoder_layers=4`, `dim_feedforward=384`, `pairwise_neighbors=16`, `pooling=attention_mean_sum_count_concat`, `position_encoding=none`, `pairwise_time_transform=raw`, `pairwise_distance_transform=raw`, `batch_size=32`, `learning_rate=8e-4`, `epochs=10`). TensorBoard showed steady optimization through the full run: train loss improved from `1.342517` to `0.903591`, train accuracy from `0.418823` to `0.554996`, and validation loss from `1.006641` to a best of `0.939720` at epoch `9`. Validation accuracy improved from `0.470070` to a best of `0.538747` at epoch `9`, then stayed essentially flat at epoch `10` (`0.538283`), so this run looks like a real but modest gain rather than a broken training job.

The saved metrics confirm that the main weakness is still class `1`. Validation macro-F1 reached `0.527376`, but class-`1` recall was only `0.313305` and class-`1` F1 was `0.360494`; on test those dropped to `0.290415` recall and `0.339181` F1. Test accuracy finished at `0.532468` with macro-F1 `0.518452`, and the confusion matrices show that true class `1` is still most often pushed toward class `0`, with a secondary spillover into class `2`. Promotion note: keep this run as a stronger capacity reference, but do not treat it as the new best ablation yet because the middle-class confusion remains the limiting factor.
